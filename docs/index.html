Pick Rate

Ideally, card strength would be evaluated using metrics like play win rate or draw win rate. However, we do not have access to such data, so that approach is not an option.

Since we only have 3‑0 decklists (without draft order), we look at which cards were available during the draft and which ended up in the 3‑0 decklist. We work under the assumption that cards which make it into a 3‑0 deck are better than those that do not. (Claiming that a pick‑14 card is strong may sound questionable, but this is the data we must work with.)

A significant limitation is that we do not know exactly which cards were available during each draft. Instead, we use the expected number of times a card should have appeared in a draft, calculated from the draft file’s pack structure and card distribution.

How Pick Rate is Calculated

The formula is:

Pick_rate(card) = total_count(card) / (draft_avg(card) × total_decks) * 100%

This is a simplification, because there are multiple slightly different draft file versions. We must use draft_avg from the version that corresponds to each 3‑0 decklist. Since players do not always host draft sessions with the latest file, we also try to determine which draft version was actually used for each deck.

Hero‑Specific vs. Global Pick Rate

You may have noticed that pick rates in this analysis differ from those on other pages. That is because we calculate hero pick rate using the formula above, but only over decks belonging to a specific hero. The main reason is to obtain meaningful numbers for cards shared by multiple heroes.

Note that this approach inflates class‑specific cards, because they face much less competition, due to some player playing a different hero.

Weighted Pick Rate

We also compute the weighted pick rate as:

Weighted Pick Rate = Σ(Hero_Pick_rate(card)) / Number_of_available_heroes

This is especially useful in an unbalanced metagame, where some heroes are much stronger than others. For example, in ROS, Earth heroes performed significantly better than Lightning heroes. This makes Earth cards have higher raw pick rates, but the weighted pick rate corrects for that imbalance.

Interpreting Pick Rate (Beyond Sorting)

A general rule of thumb: a card is decent if its pick rate exceeds 100% / (expected number of decks that can play this card).

  • For a generic card playable by all 8 heroes: 12.5% (100/8) is the threshold.
  • For a class card in a balanced three-hero meta: 33.33% (100/3) is the threshold.
